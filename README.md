# Q-law + Collocation

## Installation

```bash
pip install -e .
```

## Run

Petropoulos' "Case A", with $\eta = 0$:

```bash
python scripts/petr_a1.py
```

Petropoulos' "Case A", with $\eta > 0$:

```bash
python scripts/petr_a2.py
```

## Remarks

The sim itself uses modified equinoctial elements for dynamics, but we go guidance in Keplerian elements.
